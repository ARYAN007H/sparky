# Legacy v1 profile storage fixture

This fixture is generated with the public `tinystoragedrivers` ports from the
historical v1 implementation at commit
`0c6dcfce57201fadd830431f36fd759c3baa897a`. It is deliberately generated by
`StorageBackend::for_scope` and `DocumentStore`, not by writing TSD's SQLite
tables directly. The current host reads this database through its legacy
inventory adapter.

The standalone generator is under `generator/`; it is not a workspace member
or product dependency. Regenerate into a persistent caller-selected directory:

```sh
cargo run --locked --manifest-path crates/openhuman-core/src/storage/import/fixtures/legacy-v1-profile/generator/Cargo.toml -- /absolute/path/to/storage.db
```

The generated database is a small authentic v1 storage database. It includes
profile registry and lease rows, plus representative old owner records in
profile and module scopes. The fixture test separately verifies legacy files
that are not stored in this database; those sources are not conflated with
TSD's inventory.
